# Fence Site Master

Premium fence-contractor website master used to create personalized prospect previews.

## Important
This repository is a fictional sales/demo concept. Do not present Ironwood Fence Co., its contact information, service area, statistics, or review content as a real business.

The master site includes `noindex,nofollow`. Keep that directive on prospect previews. Remove it only when a paying client's real site is ready for public indexing.

## Prospect customization checklist
Before sending a preview, replace and verify:
1. Business name and initials/logo
2. Page title and meta description
3. Phone number and every `tel:` link
4. Email address and every `mailto:` link
5. Hero copy if the prospect has a clear specialty
6. Actual services offered
7. Service area/cities
8. Project photos — client-owned or properly licensed only
9. Review — verified public/client-supplied review only
10. Estimate/process language so it matches the real workflow
11. Footer business information
12. Form behavior and approved lead destination

## Never invent
Do not fabricate years in business, project counts, star ratings, licensing/insurance claims, warranties, financing, awards, affiliations, service areas, reviews, prices, turnaround times, or other business facts.

## Prospect preview
- Keep the DEMO CONCEPT banner.
- Keep `noindex,nofollow`.
- The form may remain demo-only.
- Clearly distinguish placeholders from verified prospect information.

## Paid production site
- Use only verified business information.
- Replace all placeholder/demo copy.
- Connect and test the real lead form.
- Add the client's domain and canonical URL.
- Add production social/share metadata.
- Remove `noindex,nofollow` only when approved to go live.
- Test phone, email, navigation, form, desktop and mobile.
- Confirm image rights.
- Add analytics/search tools only with client approval.

## Fast personalization workflow
Duplicate this repository/project for the prospect rather than editing the master. Search `index.html` for `Ironwood`, `281`, `ironwoodfence.example`, `Your City`, `DEMO`, and `REPLACE` to find the main customization points.

Keep the master clean so every prospect starts from the same reliable baseline.
